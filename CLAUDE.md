# CLAUDE.md - instructions for Claude Code in this repository

## What this repo is
A bilingual (FR/EN) Power BI semantic model and report on **synthetic** school vision-screening data (Togo, 2024-2026).
Portfolio project: quality of modelling, DAX, bilingual design and documentation matters more than speed.

## Read before doing anything
1. `docs/DESIGN_GUIDEBOOK.md` - **the design brief**. Canvas, grid, positions, colours, fonts, KPI anatomy, pages, and the "what we do NOT want" list. Follow it literally; do not invent layout or colours.
2. `docs/expected-kpis.md` - the values the report must show. Any mismatch is a bug to report, not to hide.
3. `dax/measures.dax` (model measures, field parameters, RLS) and `dax/measures-report.dax` (report-layer measures).

## Project layout
- `data/*.csv` - star schema, UTF-8 with BOM, regenerated by `scripts/generate_data.py` (seed 2026). Never edit CSVs by hand.
- `powerbi/VisionScreening.pbip` + `powerbi/VisionScreening.SemanticModel/` + `powerbi/VisionScreening.Report/` - the PBIP project (PBIR report, TMDL model).
- `powerbi/themes/vision-screening-light.json` - the report theme (default). Dark theme exists but dark mode is out of scope for v1.
- `screenshots/` - final captures, named per `docs/CAPTURE_CHECKLIST.md`.

## Rules
- Use the **powerbi-authoring** plugin skills: `powerbi-report-design` / `powerbi-report-authoring` for the report, `semantic-model-authoring` + Power BI Modeling MCP for the model. Do not guess PBIR JSON; use `powerbi-report-author` catalog / formatting lookups and run `powerbi-report-author validate` after each batch.
- After each page change: reload Power BI Desktop, take a screenshot, compare it with the guidebook positions and the expected KPIs, then fix before moving on.
- **Every piece of visible text is bilingual**: bind titles, buttons and captions to `Lbl …` or caption measures (field value). Axis / legend text comes from field parameters. Never type a literal title.
- Detailed visuals use `Correction Need Rate (Safe)` (small-cell suppression < 10 students).
- Single-direction relationships only. No bidirectional filters, no dual axis, no pie / donut / gauge.
- Measures go in the `_Measures` table with the display folders written in the `.dax` files.
- Do not change `scripts/generate_data.py` or the CSVs unless explicitly asked; if you do, re-run `python scripts/expected_kpis.py` and update the docs.
- Do not commit: `.pbi/localSettings.json`, `.pbi/cache.abf`, personal notes (see `.gitignore`).
- Work one page at a time and stop for review after each page.
